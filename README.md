# ticket-management-system

## About
Ticket Management System - Data Analysis project for LogicVeda.

## Structure
- data/raw/ - original data, do not edit
- data/clean/ - cleaned data
- notebooks/ - analysis, one notebook per question
- reports/ - charts and final report

## How to run
1. pip install -r requirements.txt
2. Open notebooks/ in Jupyter
3. Run the notebooks in order
